# Élevé Bakery

A responsive, single-page artisan bakery website built with semantic HTML, CSS, and vanilla JavaScript. All project files are in this folder; there are no local subfolders or framework dependencies.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. The bakery photography and Google Fonts are loaded from their respective external services, so an internet connection is needed for those visual assets.

## Interactions

- Responsive navigation, active section indicator, scroll progress, and reveal effects
- Menu and cake category filters
- Add-to-order feedback and item count (frontend demonstration only)
- Cake detail feedback
- Keyboard-accessible gallery lightbox with previous/next controls
- Testimonial carousel with autoplay, arrows, and dots
- Validated custom cake request and newsletter forms (no backend connection)

## Note

Élevé Bakery and its contact information are fictional. Order and newsletter submissions are handled only in the browser and are not transmitted or stored.
